# Day 28 – Outlier Detection

## Objective
To identify unusual values in a dataset using a box plot.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
In this task, I created an employee salary dataset and performed outlier detection using the IQR method.

I calculated Q1, Q3, and IQR to identify values outside the normal range. I also created a box plot to visualize the salary distribution.

## Key Learnings
- Understood outliers.
- Learned the IQR method.
- Identified unusual values using Pandas.
- Created box plots using Matplotlib.

## Result
Successfully identified a potential outlier in the employee salary dataset using statistical calculations and visualization.

## Conclusion
This task helped me understand how to detect unusual values in a dataset and visualize them using Python.
